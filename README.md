# Mangал City — Avansbot

Сейчас включён **демо-режим без базы данных и без секретов**, чтобы сначала быстро проверить интерфейс WebApp в Cloudflare.

## Что работает в демо

- добавление аванса;
- имя, телефон, сумма, дата банкета, необязательное время и комментарий;
- дата и время получения аванса ставятся автоматически;
- несколько авансов для одного банкета;
- ближайшие банкеты и календарь;
- итоги за сегодня и общий итог;
- редактирование записи;
- история изменений;
- адаптивный интерфейс Mangал City.

### Важно

В демо-режиме данные сохраняются в `localStorage` браузера/Telegram WebView.  
Это означает: данные видны только на конкретном устройстве и могут исчезнуть после очистки данных приложения. **Для реальной работы ресторана позже подключим D1.**

Уведомления администратору, общий доступ между сотрудниками, Telegram `/id` и ежедневный отчёт требуют серверной части/хранилища и будут включены после подключения базы.

## Cloudflare

Репозиторий можно подключить напрямую к Cloudflare. В демо-режиме нет D1 binding и не нужны GitHub Actions secrets.

Worker name:

```
mangal-city-avansbot
```

Entry point:

```
src/index.js
```

Assets:

```
public/
```

Для локальной проверки:

```bash
npm install
npm test
npm run check
npx wrangler dev
```
