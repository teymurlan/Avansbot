# Mangал City — Avansbot

Telegram-бот + Mini App для учёта предоплат за банкеты ресторана **Mangal City**.

## Текущая архитектура

Приложение использует **Cloudflare Durable Object** как единое общее хранилище. Отдельную D1-базу создавать не нужно.

Все сотрудники видят одну и ту же базу:
- банкеты;
- предоплаты;
- суммы;
- статус сдачи в кассу;
- историю изменений.

Изменения автоматически синхронизируются между устройствами.

## Основные функции

- быстрое внесение предоплаты;
- серверная дата и время получения;
- фиксируется сотрудник, который внёс предоплату;
- несколько предоплат на один банкет;
- ближайшие банкеты;
- поиск по имени и телефону;
- фильтры «Все / Сегодня / 7 дней»;
- предупреждение о повторном телефоне;
- «Сегодня в кассу» — сумма авансов банкетов на текущую дату;
- администратор может отметить аванс как сданный в кассу;
- сданные авансы зачёркиваются, но не удаляются;
- полный audit log только для администратора;
- уведомление администратору о каждом новом авансе;
- уведомление при изменениях и работе с кассой;
- ежедневная сводка в 23:55 по Москве;
- команда `/id`;
- команда `/start` с кнопкой открытия Mini App;
- перенос старых локальных записей в общую базу.

## Доступ

Cloudflare Variables and Secrets:

```
TELEGRAM_BOT_TOKEN=...
ADMIN_IDS=835372319,SECOND_ADMIN_ID
ALLOWED_IDS=STAFF_ID_1,STAFF_ID_2
WEBAPP_URL=https://avansbot.example.workers.dev
WEBHOOK_SECRET=...
INIT_DATA_MAX_AGE_SECONDS=86400
```

`ADMIN_IDS` — администраторы через запятую.  
`ALLOWED_IDS` — сотрудники через запятую. Администраторов туда дублировать не нужно.

## Cloudflare

`wrangler.toml` автоматически создаёт Durable Object namespace при deploy:

```toml
[[durable_objects.bindings]]
name = "AVANS_STORE"
class_name = "AvansStore"

[[migrations]]
tag = "v1"
new_sqlite_classes = ["AvansStore"]
```

Cron:

```
55 20 * * *
```

Это 23:55 по Москве.
